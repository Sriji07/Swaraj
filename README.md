**Project Name:** Swaraj  
**Type:** E-voting website  

**Technologies Used:**  
- **HTML, CSS, JavaScript:** Core technologies used for front-end development, enabling structured content, styling, and interactivity.  

**Key Features:**  
- **Responsive Design:** Utilizes CSS media queries for an optimized layout across various devices, ensuring a consistent user experience.  
- **Dynamic Interactions:** JavaScript is employed for client-side form validation and real-time feedback to enhance usability during the voting process.  
- **Accessibility:** Adheres to WCAG standards, ensuring user-friendly navigation for all participants, including those with disabilities.  
- **Security Focus:** Implements secure coding practices and encryption to safeguard user data and ensure the integrity of the voting process.  

**Objective:**  
To facilitate civic engagement by providing a simple, efficient, and secure voting platform, encouraging user participation in democratic processes.
